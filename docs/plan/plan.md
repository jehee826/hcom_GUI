## 2. 다음 작업: Codex Desktop 스타일 UI 전면 개편

기존 3단 카드형 UI를 **Codex Desktop 앱 화면 구성**에 맞춰 전면 정돈한다. 핵심 변경 방향은 다음과 같다.

- **좌측:** 아이콘 레일(`48px`) + 초경량 프로젝트 사이드바(`~232px`)로 탐색 영역 정리.
- **중앙:** 상단 2줄 컨트롤 바를 없애고 미니멀 헤더(`44px`) + **카드 테두리 없는 플랫 대화 캔버스** + **권한·모델·추론·전송이 통합된 하단 플로팅 컴포저**로 재구성.
- **우측:** Codex 앱의 `결과물 / 하위 에이전트 / 소스` 플로팅 카드 구조를 그대로 채택하되, **메인 섹션에 우리 앱의 워커(기본 접힘 + 펼침 시 설정·로그·직접 대화)**를 배치.

### Phase A · 4-Zone 셸 & 디자인 토큰 재정비

- **작업 대상:** [`src/web/index.html`](../../src/web/index.html), [`src/web/styles.css`](../../src/web/styles.css)
- **세부 항목:**
  1. **디자인 토큰 정리:** 순백 캔버스(`#FFFFFF`), 초경량 연회색 사이드바(`#F9F9FA`), 헤어라인 테두리(`#EBEBEF`), 부드러운 pill 배경(`#F2F2F4` / `#ECECEF`), 그림자 최소화.
  2. **좌측 아이콘 레일 (`48px`) 추가:**
     - 상단: `hcom_gui` 다크 엠블럼.
     - 중단: 프로젝트 사이드바 토글, CLI 진단 모달, 인계 기록 빠른 이동/모달, `hcom` 메시지 로그 토글.
     - 하단: 앱 버전·업데이트 모달 버튼 + CLI 상태 점.
  3. **좌측 프로젝트 사이드바 (`~232px`, 접이식):**
     - 헤더: `hcom_gui` 타이틀 + 필터/검색 입력 토글(프로젝트 검색).
     - 상단 액션: `+ 새 프로젝트 등록` (아이콘 + 텍스트의 가벼운 행 버튼).
     - 프로젝트 리스트: 폴더 아이콘 + 프로젝트명 + 상태 점 + 브랜치 요약(활성 프로젝트는 `#ECECEF` 둥근 배경).
  4. **미니멀 중앙 상단 헤더 (`44px`):**
     - 좌측: 폴더 아이콘 + 현재 프로젝트명 + 브랜치/격리 뱃지(클릭 시 경로·`HCOM_DIR`·`threadId` 확인).
     - 우측: `시작 / 재개`, `중지` 경량 버튼 + 우측 인스펙터 카드 토글 아이콘.
     - 기존 2줄짜리 `#projectBar` 제거 → 대화 영역 수직 공간 대폭 확보.

### Phase B · 플랫 대화 캔버스 & 하단 플로팅 컴포저 통합

- **작업 대상:** [`src/web/index.html`](../../src/web/index.html), [`src/web/styles.css`](../../src/web/styles.css), [`src/web/app.ts`](../../src/web/app.ts)
- **세부 항목:**
  1. **사용자 메시지:** 우측 정렬 연회색 말풍선(`#F3F3F5`, `border-radius: 18px`, 테두리 없음).
  2. **AI 응답 플랫화:**
     - 외곽 `.assistant-card` 테두리·그림자 제거 → 순백 캔버스에 본문이 바로 흐르는 에디토리얼 스타일.
     - **경량 XSS-safe 마크다운/코드 블록 렌더러 추가 (`textContent` 기반 DOM 생성, `innerHTML` 0건):** 제목/굵은 글씨/목록/인라인 코드/펜스 코드 블록(상단 언어 라벨 + `복사` 버튼 포함, Codex의 `</> 일반 텍스트` 카드 스타일) 지원.
     - **추론 요약 & 상세 로그:** 응답 상단에 가벼운 1줄 추론 설명(실행 중 펄스 점 + `▾` 펼침) 배치, 펼치면 기존 `ProgressLogEntry` 타임라인 표시.
     - **응답 하단 액션 바:** 복사 버튼, 완료 시각(`오후 1:17` 형식), 위임/단계 요약 배지, 진행 중에는 `취소` 버튼.
     - **인라인 액션 카드:** `waiting_user`(질문·선택지·답변 입력)와 `waiting_approval`(명령 상세·`승인하고 계속`/`거절`)만 옅은 회색 카드로 강조 표시.
     - **좌측 턴 미니맵(선택):** 중앙 왼쪽 여백에 요청별 얇은 틱 마크를 표시해 클릭 시 해당 턴으로 스크롤.
  3. **하단 플로팅 컴포저 (`max-width: 740px`, `border-radius: 20px`):**
     - 입력창: `"Codex와 함께 작업하세요"` (직접 워커 대상 선택 시 `"[워커명]에게 직접 메시지를 보내세요"`).
     - 하단 좌측 툴바:
       - `+` 대상 전환 버튼/셀렉터 (`Codex 오케스트레이터` ↔ 개별 워커 직접 전송).
       - **Codex 권한 셀렉터** (보더리스 인라인 드롭다운: `작업폴더 쓰기` · `읽기 전용` · `전체 허용`).
     - 하단 우측 툴바:
       - **Codex 모델 + 추론 속도 셀렉터** (예: `GPT-6.1 Sol · medium`, 보더리스 인라인 드롭다운 + 목록 새로고침).
       - **원형 다크 전송/중지 버튼** (`32×32` `#111111` 원형 버튼; 입력 전송 또는 활성 요청 취소).

### Phase C · 우측 플로팅 워커 인스펙터 카드

- **작업 대상:** [`src/web/index.html`](../../src/web/index.html), [`src/web/styles.css`](../../src/web/styles.css), [`src/web/app.ts`](../../src/web/app.ts)
- **세부 항목:**
  - 기존 고정 우측 사이드바(`border-left`)를 **여백이 있는 둥근 플로팅 카드(`border-radius: 16px`, `1px solid #EBEBEF`, `#FAFAFB`~`#FFFFFF`)**로 전환.
  - 카드 내부를 Codex 우측 패널의 3섹션 리듬으로 구성:
    1. **워커 (`워커` + 우측 `+` 추가 버튼)** — 스크린샷의 `결과물` 위치:
       - 기본 접힘: 1줄 컴팩트 행(상태 점 · 워커명 · 모델/권한 요약 · `▾`). 작업 중에는 한 줄 라이브 상태 표시.
       - `▾` 펼침: 모델·추론·권한 드롭다운, `시작/재개`·`중지`·`설정 재적용`, 온디맨드 **생각·도구 로그**(`hcom transcript` + 라이브 이벤트), **워커 전용 직접 대화 입력창**.
    2. **실행 활동 (`hcom`)** — 스크린샷의 `하위 에이전트` 위치:
       - 현재 프로젝트의 활성 워커 수 · 완료된 위임 수 · 최근 `hcom` 메시지 건수 요약, 클릭 시 `hcom 세션 메시지` 리스트 펼침.
    3. **프로젝트 · 인계** — 스크린샷의 `소스` 위치:
       - 브랜치 · 커밋 · `HCOM_DIR` 격리 상태 요약 행, 클릭 시 인계 기록(목표·테스트 결과·다음 작업·최근 보고/검토) 아코디언 펼침 및 저장.

### Phase D · 검증 · 패키징 · 병합

1. **기능 무손실 확인:** 기존 PR #1~#8의 모든 API 연동, SSE 실시간 메모리 패치, `visibilitychange` 절전, XSS-safe DOM(`innerHTML` 0건), 키보드 단축키(`Enter`/`Shift+Enter`) 유지 확인.
2. **반응형 확인:** 데스크톱(`1280×800`, `1440×900`) 및 좁은 창(`<960px` 드로어 전환) 레이아웃 깨짐·오버플로 없음 확인.
3. **자동 검증:** `npm run typecheck`, `npm run build`, `npm test` (전체 통과), `git diff --check`.
4. **시각 확인 & 패키징:** 실제 렌더링 화면 확인 후 `npm run dist`로 NSIS 단일 설치 파일(`release/hcom_gui-1.0.0-x64-setup.exe`) 재빌드.
5. **브랜치 정리:** 기능 브랜치(`feat/codex-style-ui-redesign`) → PR → `main` 병합 → 병합 브랜치 로컬·원격 삭제.

### 통과 기준

- 업로드된 Codex Desktop 화면과 동일한 4-Zone 비율, 라이트 모노크롬 톤, 플랫 대화 피드, 하단 통합 컴포저, 우측 플로팅 카드 구조를 갖춘다.
- 우측 플로팅 카드의 메인 섹션에서 워커를 기본 접힘 상태로 보고, `▾`로 펼쳐 모델·추론·권한 변경, 로그 조회, 직접 대화가 모두 동작한다.
- 상단 컨트롤 바 제거 후에도 Codex 모델·추론·권한 변경이 하단 컴포저에서 1클릭으로 동작한다.
- 모든 응답·코드 블록·로그는 `textContent` 기반 DOM으로 렌더링되어 HTML/스크립트 주입이 불가능하다.
- `npm run typecheck`, `npm test`, `npm run dist`가 오류 없이 통과한다.

## 3. 이후 로드맵

1. **폰 원격 접속 (Tailscale Serve):** Windows 루프백 서버에 Tailscale Serve HTTPS + 일회용 페어링 + 세션 쿠키를 연결해 승인된 폰에서 동일 UI로 모니터링·지시 수행(로컬 경로 등록 제외).
2. **첫 정식 릴리즈:** 사용자 버전 지시 시 버전 브랜치(`1.0.0` 등)에서 `main` PR 병합 및 GitHub Actions Windows 설치 파일 릴리즈 파이프라인 구성.
